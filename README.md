# Lock Mechanics — 鍵のしくみパズル

透明な錠前の中をのぞき、**仕組みを理解して、鍵そのものを削って作る**パズルゲーム。
ピッキングの簡略ミニゲームではなく、実在する 8 種類の錠前機構をそれぞれ別のルールとして遊べます。

スマホ縦画面を基本に設計した Web ゲームです（PC ブラウザでも遊べます）。

## 遊び方

1. 錠前の内部（ピン・ウェハー・レバー・ディスク…）を観察する
2. 下の加工台で鍵を削る（タップで1段／ドラッグでまとめて）
3. **差し込む** → 部品が鍵に押されて実際に動く
4. **回す** → 揃っていれば「カチッ」と回って OPEN、ダメなら引っかかった部品が赤く光る
5. **抜く** → 修正。削った金属は戻せないので、削りすぎたら **新しいブランク** から

★3 条件：規定回数以内の試し挿し＆ブランク1本でクリア。

## 収録している錠前（全 8 章・36 ステージ）

| 章 | 錠前 | 考える軸 | 特殊ステージ |
| --- | --- | --- | --- |
| 1 | ピンタンブラー錠 | 高さ（ピンの長さ→削る深さ） | のぞき窓 / インプレッション（中が見えない） |
| 2 | ウェハータンブラー錠 | 高さ（板の窓位置） | 両面ウェハー（鍵の上下両辺） |
| 3 | ウォード錠 | 形（鍵の輪郭、つながり） | スケルトンキー |
| 4 | レバータンブラー錠 | 持ち上げ量（刃の長さ） | 変則ゲート |
| 5 | チューブラー錠 | 円形配置 | 8本ピン |
| 6 | ディンプル錠 | 位置＋深さ（2列） | 深さ0のピン |
| 7 | ディスク・ディテイナー錠 | 角度 | 偽ゲート |
| 8 | 磁気＋機械式錠 | 形＋磁極 | 最終ステージ |

各章の最初に仕組みの解説、クリア時に実物の豆知識が出ます。
章をクリアすると、その錠前の **フリープレイ（ランダム生成・必ず解ける）** が解放されます。

## 開発

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # 全ステージが解けること等のテスト
npm run build      # dist/ に静的ファイルを出力
npm run build:single  # dist/lock-mechanics.html に1ファイル版を出力
```

- `?stage=4-2` でステージへ直接移動、`?unlock` で全ステージ解放（デバッグ用）
- 画像・音声アセットなし：描画は Canvas 2D、効果音は Web Audio で合成
- 進行状況は `localStorage` に保存
- PC ではキー操作可：Space 差し込む／抜く、R 回す、N 新しいブランク、Esc 一覧へ

### 構成

```
src/
  main.ts            画面遷移（タイトル / 章 / ステージ / プレイ / クリア）
  stages.ts          章・ステージ定義（正解コードや配置はここ）
  core/mechanism.ts  全錠前共通の状態機械（加工→差す→回す→開錠／失敗→抜く）
  core/sfx.ts        合成効果音
  locks/*.ts         錠前ごとのモデル・描画・鍵加工UI
tests/stages.test.ts 全ステージの解答可能性テスト
```

新しいステージは `src/stages.ts` に追加するだけで遊べます（テストで解けるかも自動チェック）。

## 公開

### プレビュー（ブラウザで直接開ける1ファイル版）

```bash
npm run build:preview   # preview/index.html と preview/unlocked.html を出力
```

`preview/` はコミットしておき、raw.githack.com 経由でスマホのブラウザから開けます。
`unlocked.html` は全ステージ解放の確認用（進行データも通常版と別に保存）。

### GitHub Pages

`main` ブランチへの push で GitHub Actions がビルドし GitHub Pages へデプロイします
（リポジトリの Settings → Pages → Source を「GitHub Actions」に設定してください）。
`dist/` は相対パスで出力されるので、任意の静的ホスティングにそのまま置けます。
